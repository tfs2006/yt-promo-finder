How To Use This Ad Library Finder

  1. Enter a brand name, domain, competitor, or product keyword.
  2. Select your region to search ads shown in that country.
  3. Click Find Ads to search the Meta Ad Library and see real ads with their text, start date, and platforms.
  4. Use Open All Ads to open every ad found in the Meta Ad Library, or open one ad at a time.

Pro tip: start with broad brand terms, then refine with exact domain names for tighter advertiser matching.

What You Will See

Every search returns real ads from the Meta Ad Library, up to 50 per search. Each result card shows the advertiser page name, the ad headline and body text, the date the ad started running, whether the ad is still active, the platforms it runs on, and a link to view the original ad in the Meta Ad Library.

Example: a search for "nike" with the region set to US returned 30 real ads in a live test. A typical result from that search shows an advertiser page name such as Nike, the ad creative as published, a start date, an Active status, platforms listed as Facebook and Instagram, and a View ad link that opens the original in the Meta Ad Library.

If a search returns no ads, try a brand name or a broader keyword. Some advertisers run no ads in the selected region.

Ad Library Finder FAQ

Is this an ad spy tool?

This tool searches the public Meta Ad Library and shows real ads with their text, start date, and platforms. It does not bypass platform privacy controls.

Which platforms are covered?

Facebook and Instagram ads from the Meta Ad Library. Each result links to the original ad so you can verify it yourself.

What should I search first?

Start with brand keywords, then test domains and offer phrases to map a full competitive ad landscape.

How much does a search cost?

Each search uses 2 credits, charged only after a successful search. Sign in with Google to get 3 free credits, plus 1 free credit every day. Credit packs start at $9 for 25 credits.

Which regions can I search?

You can search ads shown in the US, Canada, the United Kingdom, or Australia. Pick the region where your audience or your competitors run ads.
