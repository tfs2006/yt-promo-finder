How to Find Unlisted YouTube Videos

This is the safest and most reliable method: scan public playlists on a channel and identify videos whose visibility is set to unlisted.

Step-by-step workflow

  1. 1) Start with a channel URL (channel link, @handle, or channel ID).
  2. 2) Scan public playlists and collect included video IDs.
  3. 3) Resolve video visibility status via YouTube API metadata.
  4. 4) Return discoverable unlisted videos with title, date, and watch link.
Run the Unlisted Finder

What this method cannot find

  • Unlisted videos that are not in any public playlist
  • Private videos
  • Members-only content
  • Anything requiring brute-force URL guessing
